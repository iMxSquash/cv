# Security Policy

## Supported versions

Only the code currently on `main` (as deployed on `cv.elwen.dev`) is supported.

| Version                | Supported          |
| ---------------------- | ------------------ |
| `main` (latest deploy) | :white_check_mark: |
| Older tags             | :x:                |

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Report it privately via [GitHub Security Advisories](https://github.com/iMxSquash/cv/security/advisories/new) ("Security" tab > "Report a vulnerability"), or by email to contact@elwen.dev.

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce (URL, request, payload)
- Any suggested fix, if you have one

## Response process

- Acknowledgement within 7 days.
- Fix and deployment as soon as possible depending on severity.
- Coordinated disclosure: please do not publish details before a fix is deployed. Credit is given in the release notes if you wish.
